AgroTrace

Прослеживаемость сельхозпродукции «от поля до прилавка». Одно и то же приложение на React, Angular и Svelte — по общему контракту OpenAPI и с одной дизайн-системой «Поле».

React 18

Vite, React Router, TanStack Query
Открыть React Страница партии

Angular 18

Standalone-компоненты, signals
Открыть Angular Страница партии

Svelte 5

SvelteKit, runes
Открыть Svelte Страница партии

Демо-доступ

Сервера нет: API имитируется прямо в браузере, демо-данные и ваши изменения хранятся только в вашем браузере.

Пароль всех пользователей — agrotrace-demo. Например:

  • zarya.head@agrotrace.test — хозяйство
  • inspector.head@agrotrace.test — инспектор
  • admin@agrotrace.test — администратор

Публичная страница партии по QR-коду открывается без входа. Исходный код — github.com/fxrgxttxn/agrotrace-frontends.
